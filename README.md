# Simple Line Editor in C

## Project Description
A simple command-line text editor developed in C. It stores document lines in an array of strings and allows users to insert, delete, and display lines.

- Add your actual team member name(s) here.

## Implemented Features
- Insert a line at a specified position.
- Delete a line by line number.
- Display all document lines with line numbers.
- Validate line positions and handle an empty document.

## Data Structure
An array of strings is used to store document lines. It is easy to implement and suitable for a small document with a fixed maximum capacity.

## Requirements
- GCC compiler
- Terminal or Command Prompt

## Compile
```bash
gcc line_editor.c -o line_editor
```

## Run

**Windows:**
```bash
.\line_editor.exe
```
